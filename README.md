# Задание 1

## Задача 1

### Текст задачи

Первый массив, размерностью n х m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по диагоналям параллельным главной, начиная с правого верхнего угла
Второй массив, размерностью n х n, заполняется случайными числами так, что в каждом столбце получается убывающая последовательность элементов
Третий массив, размерностью n х n, заполняется для произвольного n так же, как для n=5 (спираль из центра)

### Алгоритм решения

1. Создать класс `Matrix` с единственным приватным полем `int[,] _data`
2. Создать базовый конструктор `Matrix(int n, int m)` с проверкой размеров (выбрасывать `ArgumentException`, если размер <= 0) и выделением памяти под массив
3. Создать конструктор для первого массива (с клавиатуры). Внешний цикл идет по диагоналям (разность индексов `i - j` от `m - 1` до `-(n - 1)`). Внутренний цикл по строкам. Если вычисленный столбец попадает в границы `0..m-1`, считывать число через `Validator` и записывать в ячейку
4. Создать конструктор для второго массива. Заполнить матрицу случайными числами. Затем отсортировать каждый столбец по убыванию пузырьковой сортировкой (внешний цикл по столбцам, внутренние — по строкам)
5. Создать конструктор для третьего массива (спираль). Начать с центра матрицы (`n/2`, `n/2`). Двигаться по спирали (влево, вниз, вправо, вверх), увеличивая длину шага каждые два поворота, пока не заполнится весь массив
